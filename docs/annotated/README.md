# 逐行注释版

每个代码文件一份，**每一行代码上方都有一行中文注释**。

| 文件 | 原始行数 | 注释版行数 |
| --- | --- | --- |
| `ft_detector_node_annotated.cpp` | 497 | 1192 |
| `ft_tracker_node_annotated.cpp` | 198 | 466 |
| `ft_selector_node_annotated.cpp` | 39 | 100 |

说明：

- 注释版只用于学习，**不参与 catkin_make**；
- 生产代码仍是 `src/` 下的原文件，编译通过；
- 注释版因为新增了注释行，行号和原文件**不一致**；PPT/视频里的行号仍以原文件为准；
- 建议先看 `C++语法详解.md` 的语法点，再对照注释版读代码。
